# Knowledge Engineering

## Overview

This folder contains my work from the **Knowledge Engineering** module completed during the fourth year of my Computer Engineering degree.

The module explored the representation, storage, and exchange of structured information, with a focus on XML technologies and their role in knowledge representation.

## Topics Covered

Throughout the module, I learned and practiced:

- XML fundamentals
- XML document structure
- XML Schema (XSD)
- XPath
- XSLT concepts
- PHP integration with XML
- Data validation
- Structured data representation
- Knowledge representation concepts
- Client-server interaction

## Technologies

- XML
- XSD (XML Schema)
- XPath
- PHP
- XAMPP
- Visual Studio Code

## Practical Work

The practical exercises focused on creating, validating, and processing XML documents using a local development environment.

Activities included:

- Creating well-formed XML documents
- Defining XML Schemas (XSD) to validate document structure
- Querying XML documents using XPath
- Processing XML data with PHP
- Validating XML against XSD schemas
- Testing applications using a local web server with XAMPP

The use of **XAMPP** provided a local Apache and PHP environment, allowing XML-based applications to be developed and tested without requiring an external server.
