# Extended Reality

## Overview

This folder contains my work from the **Extended Reality (XR)** module completed during the fourth year of my Computer Engineering degree.

The module introduced the concepts and technologies behind **Extended Reality (XR)**, including **Virtual Reality (VR)**, **Augmented Reality (AR)**, and **Mixed Reality (MR)**. Through a series of practical labs and assignments, I developed immersive applications using Unity, created and manipulated 3D assets, and explored different methods of user interaction within virtual environments.

## Topics Covered

Throughout the module, I learned and practiced:

- Extended Reality (XR) fundamentals
- Augmented Reality (AR)
- Virtual Reality (VR)
- Mixed Reality (MR)
- Unity development
- C# scripting
- Marker-based AR
- Object tracking
- Image recognition
- Hand tracking and gesture interactions
- 3D modelling and asset creation
- XR user interaction design

## Technologies

- Unity
- C#
- Visual Studio Code
- Blender
- XR development tools and SDKs

## Practical Labs

The module consisted of a range of laboratory exercises exploring different aspects of XR development, including:

- Creating AR applications using image markers that display 3D content when recognised by a camera
- Building and importing custom 3D models created in Blender
- Detecting and interacting with 3D objects through a laptop camera
- Capturing and recognising physical objects for use within XR experiences
- Developing interactive virtual environments using Unity
- Implementing user interactions through gestures and object manipulation

## Assignments

This repository includes several individual assignments that demonstrate different XR concepts, such as:

- **3D Object Scanning:** Capturing a real-world object, converting it into a 3D model, and visualising it within both AR and VR environments.
- **Hand Interaction:** Creating an application that allows users to grab, pinch, and move virtual objects using hand-tracking interactions.
- **Team Project:** A larger collaborative XR project that combines the concepts learned throughout the module. Additional information can be found in the link: [AR_ChessGame_Group7](https://github.com/obyrnean/ARBoardGames_Group7)
