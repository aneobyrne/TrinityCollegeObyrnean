# Deep Learning Module

## Overview

This folder contains my work from the **Deep Learning** module completed during the fourth year of my Computer Engineering degree.

The module introduced the fundamentals of **Machine Learning** and **Deep Learning**, with a focus on designing, training, and evaluating neural network models using Python. All practical work was completed using **Google Colab**.

## Topics Covered

Throughout the module, I learned and practiced:

- Fundamentals of Machine Learning and Deep Learning
- Data preprocessing and preparation
- Training, validation, and testing workflows
- Model evaluation and performance analysis
- Overfitting and underfitting
- Hyperparameter tuning
- Classification problems
- Neural Networks
- Convolutional Neural Networks (CNNs)
- Performance metrics and confusion matrices

## Technologies

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
