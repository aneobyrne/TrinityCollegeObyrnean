# Information Management

## Overview

This folder contains my work from the **Information Management** module completed during the fourth year of my Computer Engineering degree.

The module focused on the principles of relational database design and management using **SQL**. It combined both theoretical concepts and practical database development, covering the complete process of designing, implementing, and querying relational databases.

## Topics Covered

Throughout the module, I learned and practiced:

- Relational database concepts
- Entity-Relationship (ER) modelling
- Database normalization
- Primary and foreign keys
- SQL Data Definition Language (DDL)
- SQL Data Manipulation Language (DML)
- SQL queries and joins
- Aggregate functions
- Nested queries
- Views
- Constraints
- Transactions
- Database design principles

## Technologies

- SQL
- Relational Database Management Systems (RDBMS)
- Entity-Relationship Diagrams (ERDs)

## Assignment

The main project in this repository is a database system designed around a zoo management.

The assignment required designing and implementing a relational database that satisfied a set of module requirements, including:

- Creating multiple related tables
- Defining appropriate primary and foreign keys
- Enforcing data integrity using constraints
- Populating the database with sample data
- Writing a variety of SQL queries demonstrating different database operations
- Using joins, aggregate functions, grouping, filtering, and nested queries where appropriate
