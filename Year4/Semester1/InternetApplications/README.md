# Internet Applications

## Overview

This folder contains my work from the **Internet Applications** module completed during the fourth year of my Computer Engineering degree.

The module focused on modern web development, covering both frontend and backend concepts required to build interactive web applications. Throughout the module, I learned how websites communicate with external services through APIs and how dynamic content can be displayed based on real-time data.

## Assignment

The main project in this repository is a **Weather Application** developed as part of the module assessment.

The application allows users to search for any city and retrieve real-time weather information through the **OpenWeatherMap API**. The retrieved data is processed and displayed in an intuitive interface, providing users with current weather conditions, forecasts, information tables, and weather-based recommendations.

Key features include:

- Search weather information for any city
- Retrieve live weather data through API requests
- Display current weather conditions and forecasts
- Present weather information in an easy-to-read format
- Generate recommendations based on weather conditions
- Responsive and user-friendly interface
